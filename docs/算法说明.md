# 神经网络反设计算法说明

## 1 为什么不能用常规监督学习

可用的实测数据只有 4 个组分（xLCF-BT 系列）加 2 个文献体系，共 6 个点。用 6 个样本训练一个"组分→性能"网络，得到的必然是插值噪声。因此本算法不把神经网络当作**性质预测器**，而把它放在两个更能发挥其长处的位置：

1. **反向生成**：给定目标活化能，直接生成满足全部物理约束的组分（MatterGen 的思路）；
2. **残差修正**：只学"规则先验错了多少"，而不是重学物理（MatterSim 的"先有普适模型、再小样本微调"思路）。

## 2 结构

```
            ┌──────────────── G_θ ────────────────┐
(Ea_t, x_t, z) ──► MLP(2+6→64→64) ──► logits(7), gate
                                        │        │
                                   softmax q    s = 0.02+0.38σ(g)
                                        └───┬────┘
                                        f = s·q      ← 亚随机 softmax
                                            │
                     x := Σ f_i a_i  (构造上满足电荷守恒)
                     Ti := 1 − Σ f_i （位点守恒）
                                            │
            ┌──────────────── S_φ ────────────┘
            │   features(f) ──► MLP(15→64→64→1) ──► ΔEa
            │   Ea_pred = Ea_prior(f) + mean_k ΔEa_k    (K=5 集成)
            └──────────────────────────────────────────
```

### 2.1 生成器（G）

输入为**目标活化能** Ea_t、**目标掺杂量** x_t 与隐变量 z∼N(0,I⁶)。输出两个头：7 个元素的 logits 与一个门控标量。

关键点是不能直接用 softmax。softmax 满足 Σf≡1，而 Σf 恰好就是 B 位总取代量 y，直接使用会让生成器只能产出"全部 B 位被取代"的非物理配方。故采用亚随机参数化：

$$f_i = s\cdot q_i,\quad q=\mathrm{softmax}(\ell),\quad s=s_{\min}+(s_{\max}-s_{\min})\,\sigma(g)$$

取 s∈[0.02, 0.40]。电荷守恒不必作为罚项，而是闭式消去：给定 f，令

$$x:=\sum_i f_i a_i,\qquad a_i=4-z_i,\qquad \mathrm{Ti}:=1-\sum_i f_i$$

则**每一个采样都精确满足** `x + Σf·(z−4) = 0`（施主 La 与受主 M 的电荷自补偿）与位点守恒。这把"带约束生成"变成了"无约束生成 + 投影"，是 MatterGen 用 adapter 保证化学式可行的同类思路，但在这里可以做到解析精确。

训练损失（全部可解析求导，无需自动微分）：

$$\mathcal{L}=\underbrace{(\hat E_a-E_a^t)^2}_{目标}+\lambda_1[\Delta r-0.06]_+^2+\lambda_2[|t-1|-0.05]_+^2+\lambda_3(x-x^t)^2+\lambda_4[y-0.34]_+^2-\lambda_5 H(f)$$

其中 Δr 为平均离子半径相对 Ti⁴⁺ 的失配，t 为 Goldschmidt 容差因子，H 为组分熵。梯度经 softmax 与门控两层雅可比回传：

对 f 的梯度求得后，
$$\frac{\partial\mathcal{L}}{\partial \ell_k}=q_k\Big(s\,g_k-\sum_j s\,g_j q_j\Big),\qquad \frac{\partial\mathcal{L}}{\partial g}=\Big(\sum_k g_k q_k\Big)\frac{ds}{dg}$$

### 2.2 残差代理（S）

不直接学 Ea，而是学 ΔEa = Ea_DFT − Ea_prior，其中先验取

$$E_a^{prior}=0.498-0.028\,\bar d,\qquad \bar d=\frac{\sum_i f_i d_i}{\sum_i f_i}$$

该式由两个 BT 体系标定点确定（Cr³⁺ d³ 实测 0.414 eV；Co³⁺ d⁶ 实测 0.295–0.370 eV）。残差化的好处是：即便只有 10 个 DFT 点，网络也只需拟合一个缓变的小量，而不会把已知的物理关系"忘掉"。

集成 K=5 个网络，用预测标准差作不确定度，采集函数取 UCB：$\mathrm{acq}=\mu-1.5\sigma$。

### 2.3 主动学习闭环

```
repeat:
    采样 N 个 (Ea_t, x_t, z) → G → f
    剪枝到 3 个组分并按 x_t 反投影（保证电荷守恒）
    过滤：y∈[0.02,0.40]、t∈[0.95,1.06]、Δr≤0.12、活性组分≥70%
    按 UCB 选 top-B 送 DFT/实验
    只更新残差网络 S，重训 G 对齐新先验
```

## 3 与文献方法的对应

| 本算法 | 对应工作 | 差异 |
|---|---|---|
| 条件生成器 G | MatterGen（Zeni et al., Nature 2025）：对原子类型、坐标、晶格做扩散，用 adapter 微调 + classifier-free guidance 推向目标性质 | 本工作不生成晶体结构，只生成组分；约束用解析投影而非适配器，故采样成功率 100% |
| 残差代理 S | MatterSim（Yang et al. 2024）：M3GNet/Graphormer 通用势，覆盖 0–5000 K、0–1000 GPa，可微调做性质预测 | 本工作用解析先验 + 小样本残差替代通用势；若算力允许，可由 MatterSim 直接给结构松弛后的能量 |
| 主动学习 | 通用贝叶斯优化框架 | 采集在组分空间而非结构空间，维度低（7 维），故用集成方差即可，无需 GP |

## 4 实现与超参

- 纯 numpy，无 torch/sklearn 依赖（集群上可直接跑）
- G：2+6 → 64 → 64 → (7 + 1)，Adam lr=4e-3，1500 步，batch=256
- S：15 → 64 → 64 → 1，Adam lr=2e-3，5 个集成，每轮 400 epoch
- 特征（15 维）：7 个组分分数 + x + d̄ + r̄ + t + 熵 H + y + 活性占比
- 种子固定 20261026，全流程可复现

## 5 验证结果（合成 oracle）

| 轮次 | 标注样本 | 训练 RMSE | 留出 RMSE |
|---|---|---|---|
| 1 | 10 | 0.0039 | 0.0041 |
| 2 | 20 | 0.0095 | 0.0159 |
| 3 | 30 | 0.0077 | 0.0079 |
| 4 | 40 | 0.0120 | 0.0088 |

注意：这一轮用的是**合成真值**（先验 + 元素间交互项 + 0.012 eV 噪声），只用于验证闭环代码通路是否正常，**不代表真实精度**。真实精度必须由 T2/T3 那批 DFT 标签给出。

## 6 局限

1. 先验 Ea 的标定点只有 2 个，斜率 −0.028 eV/d 的不确定度很大，需 T2 的 6 个组分重新标定；
2. 生成器只在"自补偿"子空间内搜索，若目标体系需要氧空位补偿（如 M⁵⁺ 掺杂），需另建约束；
3. 输出的是组分而非结构，阳离子排布的影响（x010_a 与 x010_b 的差别）尚未进入模型，须靠 DFT 补。
